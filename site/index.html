            Questions
            
        
            
        
            
          
            
            Do I need a server?
            
            
              Yes, for now: any machine that runs Docker, like an Umbrel, a
              home server or a small VPS. There is no hosted version yet.
            
            
          
            
          
            
            What happens to my data?
            
            
              It stays in the database on your server. BrainBro sends no
              telemetry, and search by meaning runs there too. An assistant
              only gets in when you approve it, and you can revoke it any time.
            
            
          
            
          
            
            Does it work without AI?
            
            
              Yes. Capturing, the inbox, boards, collections, search and the
              rest work on their own. Assistants are optional.
            
            
          
            
        
            
      
            

      
            
        
            
          
            Install it on your server
            
          
            Your notes stay on your machine. One Docker Compose stack runs everything.
            
        
            
        
            
          
            
            
            Docker Compose
            
            
            git clone https://github.com/TheBrainBro/brainbro
cd brainbro
cp stack.env.example stack.env  # your hostname and secrets
make prod-up
            
          
            
          
            
            
            Umbrel
            
            
            
              Not in the Umbrel App Store yet. In Portainer, add a stack from
              the repository with
              docker-compose.production.yml and the variables in
              stack.env.example. A Cloudflare Tunnel gives it HTTPS.
