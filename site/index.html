        A trip, start to finish

        How planning a week in Lisbon goes with Brain.

        1. Drop

          For weeks, every link, photo and voice note about Lisbon goes to the inbox, unsorted.

        2. Sort

          “Put everything about Lisbon in a collection.” Your assistant does it.

        3. Plan

          Lay out the days on a board. Claude drafts the itinerary as a note.

        4. Go

          Publish the itinerary for your friends. On the road, ask any assistant what's next.

        Install it on your server
        
          
        Your notes stay on your machine. One Docker Compose stack runs everything.
        
        
        
        
        
          
        
            
        Docker Compose
        
            
        git clone https://github.com/CarlosLugones/brain
cd brain
cp stack.env.example stack.env  # your hostname and secrets
make prod-up
        
          
        
          
        
            
        Umbrel
        
            
        
              In Portainer, add a stack from the repository with
              docker-compose.production.yml and the variables in
              stack.env.example. A Cloudflare Tunnel gives it HTTPS.
