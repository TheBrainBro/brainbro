Connect your assistant

Paste this into Claude, ChatGPT, Grok or any assistant with MCP. It walks you through the rest. 

I use Brain, a self-hosted second brain, as shared memory across my AI assistants. Help me connect you to it.

1. Read how Brain works with assistants: https://github.com/CarlosLugones/brain/blob/main/docs/mcp.md
2. Ask me for my Brain's address (like https://brain.example.com). Its MCP server is that address plus /api/mcp.
3. Walk me through adding it as a custom connector in the app we are using now, one step at a time. I sign in to Brain to allow it.
4. Once connected, list my inbox to check it works.

From then on: search Brain before answering about my notes or plans, save what I ask you to remember, and read a note before editing it.

Install it on your server

Your notes stay on your machine. One Docker Compose stack runs everything.

Docker Compose

git clone https://github.com/CarlosLugones/brain
cd brain
cp stack.env.example stack.env  # your hostname and secrets
make prod-up

Umbrel

In Portainer, add a stack from the repository with docker-compose.production.yml and the variables in stack.env.example. A Cloudflare Tunnel gives it HTTPS.
